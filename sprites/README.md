# Спрайты зданий

Файлы именуются `<type>-<level>.<ext>`, например `house-1.svg`, `factory-3.png`.

- Типы: `house`, `factory`, `warehouse`, `power-plant` (см. `src/game/buildings.ts`).
- Если спрайта для уровня нет, используется ближайший младший уровень.
- Реестр доступных уровней и расширение файлов: `src/assets/sprites.ts`
  (константы `AVAILABLE_LEVELS` и `EXT`).

## Требования к графике

- Соотношение сторон ~3:4 (например 96×128, 192×256, 384×512).
- Основание здания — по центру нижней части кадра: спрайт якорится
  низом к центру изометрической плитки (см. `.building` в `GridCell.css`).
- Прозрачный фон, без «земли» под зданием — плитка рисуется игрой.
- Проекция: изометрия 2:1 (угол как у плитки поля).

Текущие SVG — плейсхолдеры; замените их растровыми спрайтами
(PNG/WebP) и поменяйте `EXT` в `src/assets/sprites.ts`.
